# Qilian — Flame Rider

A browser 3D racing game with Blender-exported Danxia mountains, a flame guitar, and the original 夜走祁连山 soundtrack.

Play: https://fangde.github.io/qilian-flame-rider/

## Controls
A/D or arrows: steer. W/S: speed. Space: guitar flame. Shift: boost. Mouse or Q/E: aim. C: camera. P: pause. M: music.

Click Start to enable music. Touch controls are available on mobile.
